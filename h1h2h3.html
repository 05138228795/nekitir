# درس: نوشتن متن و نمایش عکس در HTML ## هدف درس در این درس یاد می‌گیریم: 1. چگونه یک عنوان در صفحه بنویسیم. 2. چگونه یک متن معمولی بنویسیم. 3. چگونه یک عکس در صفحه نمایش دهیم. 4. چگونه مسیر عکس را مشخص کنیم. --- ## ۱. تگ عنوان؛ `h1` برای نوشتن عنوان اصلی صفحه از تگ `h1` استفاده می‌کنیم. تگ `h1` از دو بخش تشکیل می‌شود: ```html

عنوان صفحه

``` تگ بازکننده: ```html

``` تگ بسته‌شونده: ```html

``` متنی که بین این دو تگ قرار می‌گیرد، به‌عنوان عنوان اصلی نمایش داده می‌شود. مثال: ```html

صفحه شخصی من

``` --- ## ۲. تگ پاراگراف؛ `p` برای نوشتن یک متن یا پاراگراف از تگ `p` استفاده می‌کنیم. ```html

من در حال یادگیری HTML هستم.

``` در این مثال: - `

` شروع پاراگراف است. - `

` پایان پاراگراف است. - متن بین آن‌ها نمایش داده می‌شود. مثال دیگر: ```html

HTML زبان ساختاردهی صفحات وب است.

``` --- ## ۳. تگ عکس؛ `img` برای نمایش عکس از تگ `img` استفاده می‌کنیم. ```html ``` تگ `img` مانند تگ‌های `h1` و `p` تگ بسته‌شونده جداگانه ندارد. ### ویژگی `src` ویژگی `src` مسیر یا آدرس عکس را مشخص می‌کند. ```html ``` در این مثال، مرورگر به دنبال فایلی با نام `photo.jpg` می‌گردد. ### ویژگی `alt` ویژگی `alt` توضیح کوتاهی درباره عکس است. ```html ``` اگر عکس نمایش داده نشود، متن `alt` به جای آن نشان داده می‌شود. همچنین این متن به موتورهای جست‌وجو و افراد کم‌بینا کمک می‌کند تا موضوع عکس را بهتر متوجه شوند. --- ## ۴. نمایش عکس اینترنتی اگر آدرس عکس در اینترنت را داشته باشیم، می‌توانیم آن را در ویژگی `src` قرار دهیم: ```html ``` در این مثال: - آدرس عکس بین علامت‌های نقل‌قول قرار گرفته است. - `alt` توضیح عکس را مشخص می‌کند. --- ## ۵. نمایش عکس داخل پروژه ابتدا در پروژه یک پوشه به نام `images` بسازید: ```text project ├── index.html └── images └── photo.jpg ``` حالا برای نمایش عکس از این کد استفاده کنید: ```html ``` چون فایل `index.html` و پوشه `images` هر دو در یک سطح قرار دارند، فقط می‌نویسیم: ```html images/photo.jpg ``` --- ## ۶. کد کامل تمرین حالا که توضیحات تگ‌ها را خواندیم، کد کامل را ببینیم: ```html صفحه من

صفحه شخصی من

من در حال یادگیری طراحی سایت هستم.

``` --- ## ۷. تمرین شاگرد یک صفحه بساز و موارد زیر را در آن قرار بده: 1. یک عنوان با `h1` بنویس. 2. یک متن کوتاه با `p` بنویس. 3. یک پوشه به نام `images` بساز. 4. یک عکس داخل پوشه `images` قرار بده. 5. عکس را با تگ `img` در صفحه نمایش بده. 6. برای عکس یک توضیح مناسب در `alt` بنویس. مثلاً: ```html

معرفی من

من به یادگیری برنامه‌نویسی علاقه دارم.

``` به این ترتیب، شاگرد ابتدا با مفهوم و کاربرد هر تگ آشنا می‌شود و سپس در کد کامل از آن‌ها استفاده می‌کند.
